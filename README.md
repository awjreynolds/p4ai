# p4ai

Exploring an evidence-gated escalation approach to compilation for resource-constrained targets: mechanical methods first, a cheaper model tier where justified, and a high-reasoning language model for unresolved decisions.

The first goal is to choose a target and define a reproducible public experiment, including the compiler boundary, baseline, hard constraints, and success criteria. P4 targets are candidates; the target choice is open.

This repository is currently in the research and decision-planning stage. It does not yet contain a compiler implementation.
