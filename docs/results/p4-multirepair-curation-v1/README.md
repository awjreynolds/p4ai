All sources derive from a common public TNA scaffold. Overlapping admission uses a twelve-table token chain and eight side lookups gated by tenant bits, with even/odd side assignment and bits 0/2 differing from the helper development example. The accumulating structure adds an observable accumulator update at every chain step; the selected extension shares one 32-bit action parameter between token and accumulator updates. Fork/join uses four diamonds, each with two independent token lookups followed by a join keyed on their outputs. Width or capacity variants within a family count as one structure. These are related synthetic programs, not independent production applications or a broad representative benchmark.

Group `a` always denotes the eight side policy tables and group `b` the twelve primary graph tables. The full menu is packing values 1–9 for either group, immediate-data suppression for either or both groups, and placement priorities +10 or -10 for either group. Each table has four fixed 80-character annotation slots. Filename, line positions, capacities, and bytes outside those slots are invariant within each case. The public IDs were assigned by ascending baseline source hash, without role or repair labels. Source-only ancestry is in `examples/p4-multirepair/evaluation/ANCESTRY.md`.
